# v1.0.0 受け入れ試験チェックリスト

この文書は、Becky! 上での実機受け入れ試験を記録するためのチェックリストです。
自動テストが成功していても、Becky! のメニュー連携・画面操作・実際の Gemini API 通信まで保証するものではありません。

## 試験環境

- Becky! Internet Mail：対象バージョンを記録
- Windows：バージョンと x86 / x64 を記録
- プラグイン：Becky-AI-Assistant-65.dll
- Gemini：利用モデル ID と実施日を記録
- API キー：有効なキーを使用。ログや試験記録には記載しない

## 自動テスト

Windows x86 Release ビルドで CTest を実行します。

- [ ] CMake Win32 構成・Release ビルド成功
- [ ] CTest 全件成功（失敗 0 件）
- [ ] DLL が Becky-AI-Assistant-65.dll として生成される
- [ ] ZIP パッケージに DLL と README.md が含まれる

現在の CTest 対象：

1. MimeTextExtractorTests：MIME、文字コード、HTML、添付除外など
2. PiiMaskerTests：自動・手動マスキング、復元、カテゴリ別設定
3. MailPromptContentTests：差出人情報・明確な署名の除外、本文保持
4. GeminiReplyPromptContentTests：返信必須条件の改行と内容保持
5. MailSignatureStripperTests：署名検出と CRLF の位置保持
6. GeminiFallbackTests：代替モデル選択条件
7. GeminiAsyncTests：ワーカー完了・キャンセル時の結果破棄
8. GeminiResponseJsonTests：Gemini 応答 JSON の解析
9. GeminiTextContinuationTests：長文回答の継続と重複除去
10. MarkdownRendererTests：相談回答の Markdown 表示
11. ConsultHistoryStoreTests：相談履歴の保存・切替・削除・上限

## Becky! 実機試験

### 1. 起動・メニュー連携

- [ ] DLL を Becky! のプラグインフォルダーへ配置し、プラグインとして認識される
- [ ] メール一覧の右クリックから AI 機能を起動できる
- [ ] メール本文表示の右クリックから AI 機能を起動できる
- [ ] 返信・全員返信の作成画面から返信文案機能を起動できる
- [ ] 新規メール作成画面から新規作成・校正機能を起動できる
- [ ] 複数メール選択時は警告し、誤ったメールを処理しない

### 2. メール本文の取り扱い

- [ ] テキスト形式メールの本文・件名が正しく扱われる
- [ ] HTML 形式メールの段落・改行・箇条書きが読みやすく抽出される
- [ ] Base64 / Quoted-Printable の本文が正しく扱われる
- [ ] 差出人情報が要約・相談・返信の Gemini 送信内容に含まれない
- [ ] 明確な署名・連絡先が要約・相談・返信の分析対象から除外される
- [ ] 添付ファイルの内容が送信対象に含まれない
- [ ] 署名判定が曖昧な本文を誤って丸ごと削除しない

### 3. 5つの AI 機能

- [ ] 要約：要点・依頼事項・期限が本文に沿って出力される
- [ ] AI相談：初回質問と追加質問が正しく処理される
- [ ] 返信：元メールにない事実や約束を勝手に追加しない
- [ ] 返信：返信に盛り込む複数の箇条書き条件がすべて反映される
- [ ] 新規作成：目的・補足条件から件名と本文が生成される
- [ ] 校正：指定した文章レベルに応じて修正の強さが変わる
- [ ] 校正：原文の意味・段落・引用を不必要に変更しない
- [ ] 校正：元の署名が重複・欠落せず、そのまま復元される

### 4. マスキング・プライバシー

- [ ] 初期状態でマスキングが OFF である
- [ ] マスキング ON で Gemini 送信前プレビューが表示される
- [ ] メールアドレス・電話番号・郵便番号・IP・住所・番号類が設定どおりにマスクされる
- [ ] 会社名・氏名・追加登録語句が設定どおりにマスクされる
- [ ] プレビューで選択した語句を手動マスキングできる
- [ ] 同一語句が複数箇所にある場合、対象箇所がすべてマスクされる
- [ ] プレビューをキャンセルした場合、Gemini API へ送信されない
- [ ] 生成結果ではマスクした語句が正しく復元される
- [ ] マスキング設定を復号できない場合、外部送信が中止される
- [ ] デバッグログ OFF では本文・プロンプトが記録されない
- [ ] デバッグログ ON でも API キー・認証ヘッダー・回答本文が記録されない

### 5. 相談履歴・画面操作

- [ ] 同じメールを再度開くと、直前の相談履歴が復元される
- [ ] 同じメールに複数の相談を作成し、切り替えられる
- [ ] 選択中の相談だけを削除できる
- [ ] 直前の質問を入力欄へ再入力できる
- [ ] Becky! 終了後に相談履歴が消去される（ディスクへ永続保存しない）
- [ ] 生成中は履歴切替・新規相談などの操作が適切に制御される

### 6. 生成結果・エラー処理

- [ ] 生成結果を編集できる
- [ ] 返信文案が通常返信・全員返信の正しい作成画面へ挿入される
- [ ] 新規メール文案が件名・本文の正しい欄へ反映される
- [ ] 校正結果は明示的な確認操作を行うまで元本文へ適用されない
- [ ] 生成機能がメールを自動送信しない
- [ ] 生成中のキャンセル要求後、完了した結果が誤って画面へ反映されない
- [ ] Becky! 終了・画面を閉じる操作中にワーカー処理が残っても異常終了しない
- [ ] API キー未設定・モデル未選択・通信失敗・HTTP エラーが原因別に表示される
- [ ] 利用できないモデルや一時障害時、設定に応じて代替モデルへ切り替わる

## 7. APIエンドポイントの保守確認

- [ ] Gemini／Groq／Workers AIの生成API、モデル一覧API、接続テスト、料金情報取得のURLを公式ドキュメントと照合した
- [ ] APIホスト名・パス・APIバージョン・認証方式に変更がある場合、生成とモデル一覧の両方を確認した
- [ ] HTTP 200だけでなく応答JSONの構造・本文抽出・finish reasonを確認した
- [ ] APIキー／Tokenが意図しないホストへ送信されないことを確認した
- [ ] API変更時は docs/API_ENDPOINT_MAINTENANCE.md と README を更新した
