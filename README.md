# Becky AI Assistant

Becky! Internet Mail向けのGemini／Groq／Cloudflare Workers AI API連携AIアシスタントプラグインです。

## 現在の機能（0.89.0）

- メール要約：Gemini／Groq／Cloudflare Workers AIに直接接続して利用可能。個人情報マスキング、送信前プレビュー、キャンセル、マスク語句の復元に対応
- 返信文案：Gemini／Groq／Cloudflare Workers AIに対応。Workers AIの返信文案は、API応答に改行がない場合も文末ごとに改行して読みやすく整形。複数ターンのAI相談：Gemini／Groq／Cloudflare Workers AIに対応
- メール校正：文章レベルを1～10段階で調整可能（レベル1は誤字・文法中心、レベル10は意味・情報を維持した積極的な表現改善）


- 対象: Win32 (x86)、Visual Studio 2022、C++17、MBCS
- メール一覧・本文表示の右クリックメニューから起動
- 対象メールは1通。複数選択時は警告して処理を中止
- MIMEテキストを抽出して要約、複数回のAI相談、返信文案の作成が可能
- AI相談の回答はMarkdownを整形して表示（見出し・太字・箇条書き・番号付きリスト・区切り線・コード表記に対応）
- AI相談の回答出力上限をGeminiは1回あたり8,192トークン、Groqは1回あたり768トークンに設定。出力上限で回答が途中終了した場合は、続きを最大2回まで自動生成して連結。重複部分を除去し、最後まで完成した回答だけを履歴に追加。自動継続しても完了しない場合や継続リクエストが失敗した場合は、不完全な回答を正常扱いせず再質問・時間をおいての再試行を案内
- HTMLメールは段落・改行・箇条書きの構造を保持し、HTML文字参照をデコード
- 要約・メール相談・返信文案では差出人情報を選択中のAIサービスへ送らず、件名と受信本文を使用。明確に識別できる署名ブロックは送信前に除外し、判定が曖昧な本文は削除しない
- メール校正では明確な署名部分をローカルに退避し、Geminiへ送らず、校正結果へ元の署名をそのまま戻す
- 相談履歴を踏まえた返信文案の作成と、Becky!の通常返信・全員返信画面への挿入に対応
- 返信・全員返信の作成画面にある「Becky AI Assistant...」メニューからも返信文案を作成し、現在開いている返信画面へ直接挿入
- 新規メールの目的・補足条件から件名と本文を作成し、編集後にBecky!の作成画面へ反映
- 新規メール・返信・全員への返信の作成画面の右クリックメニューから、入力済み本文をGeminiで校正。修正前後を並べて確認し、校正結果を編集して明示確認後に適用
- メール校正画面に「マスキングする」チェックを追加。設定画面のマスキング有効状態を初期値として表示し、校正ごとに送信前のマスキング有無を切り替え可能（初期状態は設定画面のマスキング有効状態を反映）。
- 校正では必要最小限の修正を優先し、原文の社名・宛名・署名・引用・段落・改行を省略・変更しないよう指示。マスキング対象が校正結果から欠落した場合は、本文欠落を防ぐため結果の適用を拒否。校正結果を別モデルで再校正する場合は、直前の校正結果を次の入力として使用。元の本文は適用操作を行うまで保持
- 返信に盛り込む指定条件は、Geminiへ実際の改行を保持して送信し、箇条書きの各項目を読み取りやすい形で反映
- 校正で署名を分離・復元する際、CRLF改行を含む元本文の位置を維持し、本文と署名の重複を防止
- 生成文案は編集可能。送信・送信操作は行わない
- 要約・返信・相談・新規メール作成・メール校正で共通のモデルカタログを使用
- AI相談の履歴はメールごとに保持し、相談画面を閉じて再度開いても復元。履歴一覧から複数の相談を切り替え・個別削除でき、直前の質問を入力欄へ再入力可能。Becky!終了時に消去し、ディスクには保存しない（1メールにつき最大10件の相談をメモリ内に保持、最大10メール分を管理し、古い履歴から自動削除）
- 添付ファイルはGemini APIへの送信対象外

## 複数AIサービス設定

設定画面の「AIサービス」タブで、Gemini／Groq／Cloudflare Workers AIのいずれかを選択します。選択したサービスに必要な設定項目だけを表示する構成です。

- Gemini：APIキー、モデル選択、公式モデル一覧の更新、接続テスト
- Groq：APIキー、モデル選択、公式モデル一覧の取得。メイン画面でもモデルを切り替えでき、選択内容は即時保存
- Cloudflare Workers AI：Account ID、API Token、モデル選択、公式モデル一覧の取得。メイン画面でもモデルを切り替えでき、選択内容は即時保存

各サービスのAPIキー・トークンはWindows DPAPIで暗号化して保存します。Cloudflare AI Gateway経由の接続機能と設定項目は廃止し、3サービスとも各社のAPIへ直接接続します。旧バージョンで保存したGateway経路設定は読み込み時に無効化し、Gemini／Groq／Workers AIのAPIキー・モデル設定は維持します。

Groq／Cloudflare Workers AIの公式モデル一覧取得・保存にも対応しました。Gemini／Groq／Workers AI共通のモデル評価ポリシーをGitHub上のJSONから取得し、推奨・注意・品質未評価をモデル説明欄に表示します。評価情報はローカルにキャッシュし、取得失敗時は保存済み情報を維持します。モデル一覧の最終取得日時と評価情報の更新日時も設定画面に表示します。モデル一覧APIに掲載されていることと、品質・Free枠・実アカウントでの利用可否は別々に扱います。

## 個人情報のマスキング

選択中のAIサービスへ送信するプロンプトを作成する直前に、ローカルでマスキングします。

- 自動検出の種類を設定画面で個別にON/OFF: メールアドレス、電話番号、郵便番号、IPv4アドレス、会社名、氏名、住所、口座・顧客・社員番号
- 追加登録語句も個別にON/OFF可能。会社名・氏名・部署名などを1行に1件ずつ登録
- 追加登録語句とマスキング種類の設定はWindows DPAPIで暗号化して保存
- 個人情報マスキングはメイン画面のGeminiモデル選択欄の横にある「マスキング」でON/OFF（初期値OFF、選択状態は保存）
- 設定画面ではマスキング対象の種類と追加登録語句を管理
- デフォルトGeminiモデルを設定画面で選択・保存し、要約・返信・新規作成・校正などの各画面に反映
- 校正時はマスキング用プレースホルダーの保持を明示し、欠落時は安全性を維持したまま別モデルを再試行
- マスキングを有効にすると、要約・返信・相談・新規メール作成・メール校正の実行前に送信対象情報をプレビュー表示
- プレビュー上でマウス選択した語句を手動マスキングでき、同じ語句が送信内容内に複数ある場合はすべてマスク
- マスキング確認画面はWindowsの複数行入力欄に合わせて改行コードを表示用にCRLFへ統一。API送信プロンプトの改行コードやコピー・貼り付け用の返信文案には影響しない
- 初期選択モデルはGemini 3.5 Flash-Lite（解除したい場合はプレビューをキャンセルして再表示）
- プレビューで「この内容で送信」を選んだ場合だけ選択中のAIサービスへ送信
- AIサービスから返った文案は、表示前にローカルで元の語句へ戻す
- 要約・相談・返信文案では差出人情報をGeminiへ送らず、明確な署名も除外。校正では署名をローカル退避して結果に戻す
- Gemini APIの応答待ちタイムアウトは15秒。選択モデルが利用できない場合や一時的な通信・サーバーエラー時は、料金情報で無料枠を確認済みのFlashモデルから最大2候補を優先順に順次試行
- マスキング設定を復号できない場合は、外部送信を中止

自動検出は完全ではありません。氏名・会社名・住所など、確実に伏せたい語句は設定画面に登録してください。マスキング後の情報でも文脈から個人や組織が推測される可能性があります。送信前プレビューを必ず確認してください。

## Groq／Workers AIモデル一覧の更新

設定画面の「AIサービス」タブにある各「モデル一覧取得」ボタンから、保存前の入力値を使って公式APIへ接続します。Groqは `GET https://api.groq.com/openai/v1/models`、Workers AIは `GET /accounts/{account_id}/ai/models/search?task=Text%20Generation` を使用します。Workers AIでは実験的・非推奨モデルに加え、Chat Completions非対応・Freeプラン対象外・利用規約同意が必要・アカウント権限不足・応答形式未対応を確認したモデルを除外します。Groqでは音声系・埋め込み系・利用規約同意が必要なOrpheusモデルを除外します。取得処理はバックグラウンドで実行し、既存のモデルIDを保持したまま選択リストを更新します。どちらもモデルIDは手入力できます。\n\n重要：両APIのモデル一覧応答には、Freeプランでの利用可否を確定する情報が含まれません。そのため取得したモデルは「利用可能モデル」であり、「Free対象」とは表示しません。GroqのFree枠は公式モデル料金・Rate Limits情報、Workers AIのFree枠はCloudflareのプラン・Neurons利用量に基づき別途確認してください。\n\n
### Groq／Workers AIモデル一覧の保存

GroqとCloudflare Workers AIのモデル一覧は、%APPDATA%\Becky-AI-Assistant\groq-models-catalog.txt／workers-ai-models-catalog.txt にUTF-8で保存します。次回起動時は保存済み一覧を先に読み込むため、毎回APIから再取得する必要はありません。モデル一覧の取得に失敗した場合は、最後に正常取得した一覧を保持します。これらはモデルIDのみを含むキャッシュであり、APIキーやAccount IDは保存しません。

## Gemini APIモデル一覧の更新

設定画面の「APIモデルを更新」から、保存済みAPIキーでGemini APIの `models.list` を呼び出します。

- `generateContent` 対応のGemini/Gemmaテキスト生成モデルを抽出
- 音声・画像生成・埋め込み・Live・動画などの専用モデルは除外
- モデル一覧の更新時に「有料モデル・料金未確認モデルも含める」をOFFにすると、Google公式料金ページのStandard表にあるInput priceのFree Tier列で無料と確認できたモデルだけを表示
- ONにすると、APIキーのモデル一覧に返された他のテキスト生成モデルも含める。料金区分が未分類のモデルはラベルで明示。この設定はモデル一覧の更新時だけに適用され、自動切り替えの対象モデルは変わりません
- 料金ページはMarkdown形式を優先して取得し、StandardのInput price行を解析
- 更新結果は `%APPDATA%\\Becky-AI-Assistant\\models-catalog.txt` に保存
- 要約・返信・相談・新規メール作成・メール校正は、同じ保存済みモデル一覧を使用

無料枠の判定はモデル一覧の更新時にGoogle公式料金ページから取得したStandardのInput price / Free Tier欄に基づきます。Google側のページ構成が変更され解析できない場合は更新を中止し、既存カタログを保持します。また、料金ページで無料枠ありと判定されても、APIキーの権限・割り当て・地域・提供状況によって実際の生成リクエストが拒否される場合があります。

## 応答待ち・エラー処理

- Gemini API通信のタイムアウトは全機能で統一（名前解決・接続・送信は各10秒、応答受信は15秒）。代替モデルも各候補15秒の応答待ちで順次試行。Gemini／Groq／Workers AIのAI相談およびGroqの返信・要約は、出力上限に達した場合に最大3回のAPIリクエスト（初回＋継続2回）を行う場合があります。Groqは1回の出力要求を768トークンに制限。TPM／OTPM制限に達した場合はGroq／Workers AIが返す再試行可能時間を読み取り、少し余裕を加えて待機後、同じリクエストを最大2回自動再試行。待機中もキャンセル可能。AI相談画面ではAPI応答待ちの経過時間と、TPM／OTPM回復待ちの残り秒数を表示
- 400 / 401 / 403 / 404 / 408 / 413 / 429 / 5xxを原因別に案内
- 404 / 408 / 429 / 5xx / 一時的な通信障害（タイムアウト・接続失敗・DNS一時失敗）時は、設定ONなら無料枠ありと公式料金ページで確認済みの新しいFlashモデルへ最大2候補まで自動切り替え。2.5系はプロジェクトごとの利用制限があるため自動切り替え先から除外（403 / TLS・認証・設定エラーは対象外）
- HTTP 0 の通信失敗も一時的な接続障害として判定し、次の代替候補を試行。最終エラーには選択モデルと各代替モデルの通信・HTTPエラー内容を表示
- 有料・料金未確認モデルへの自動切り替えは行わず、切り替え後は画面に使用モデルを通知。無料枠の上限やGoogle側の課金設定により料金が発生する可能性があり、無課金を保証するものではありません
- 自動切り替えは設定画面でON/OFF可能（初期値ON）。代替モデルが見つからない場合は、先に設定画面からAPIモデル一覧を更新してください
- モデル更新と接続テストはバックグラウンドで実行
- 要約・返信・相談・新規メール作成・メール校正の生成処理はキャンセルを要求可能。処理終了後に画面を閉じる

## 手動マスキング

送信内容の確認画面で選択範囲を手動マスキングした場合、選択済みプレビューを元の送信プロンプトへ確実に適用します。返信文案ではプレビューとAPI送信で同一のプロンプト生成処理を使用し、全選択時にも選択内容全体が単一の `[MANUAL_n]` トークンとして送信されます。

## デバッグログ

設定画面の「詳細デバッグログ」を明示的にONにすると、Gemini API送信内容と応答、およびGroq／Workers AIのプロバイダー・操作・モデルID・処理結果・HTTPステータス・処理時間を記録します。

- 保存先: `%APPDATA%\\Becky-AI-Assistant\\debug.log`
- 記録項目: プロバイダー名、操作種別、モデルID、処理開始・終了、HTTPステータス、成否、処理時間、エラー。Geminiでは従来どおりマスキング状態・置換語句数・送信データサイズも記録
- マスキングがONの場合のみ、APIへ送信する直前のJSONペイロードを記録
- マスキングがOFFの場合は本文・プロンプトを記録せず、メタデータのみ記録
- ログは最大約2MBでローテーションし、旧ログを `debug.log.1` に保存
- ログにはマスキング後の送信文章が残ります。マスキングは匿名化を保証せず、未検出情報が残る可能性があるため、ログの取り扱いに注意し、検証後は削除してください
- APIキー、認証ヘッダー、Geminiからの回答本文は記録しません

デバッグログは初期状態でOFFです。

## APIキー・マスキング設定の保存

Gemini APIキー、追加マスキング語句、マスキング対象設定、安定性設定（デバッグログの有効・無効を含む）は、Windows DPAPI（現在のWindowsユーザーに紐づく暗号化）で保存します。

- APIキー: `%APPDATA%\\Becky-AI-Assistant\\gemini-key.dat`
- マスキング語句: `%APPDATA%\\Becky-AI-Assistant\\pii-mask.dat`
- マスキング対象: `%APPDATA%\\Becky-AI-Assistant\\pii-options.dat`
- 安定性設定: `%APPDATA%\\Becky-AI-Assistant\\reliability-options.dat`

別のWindowsユーザーでは復号できません。平文のAPIキー・追加マスキング語句・マスキング設定は保存しません。

## テスト

実機受け入れ試験の項目と v1.0.0 判定基準は [docs/RELEASE_CHECKLIST.md](docs/RELEASE_CHECKLIST.md) を参照してください。

Gemini APIのJSON応答解析は全機能で共通化し、Unicodeエスケープ（サロゲートペアを含む）、改行・引用符などのJSONエスケープ、不正な文字列値を回帰テストします。

Win32 Releaseビルド時に回帰テストを実行します。非同期処理では、ワーカースレッドの起動順序・完了通知・キャンセル時の結果破棄を専用テストで確認します。また、Gemini API応答が2MBを超えた場合は不完全な応答を成功扱いせず、明示的なエラーとして扱います。MIME本文抽出（UTF-8 / Shift_JIS / EUC-JP / ISO-2022-JP、Base64、Quoted-Printable、入れ子multipart、HTML文字参照・段落改行、添付ファイル除外、長文・サイズ上限、空メール）、個人情報マスキング（ON/OFF、各種検出、追加登録語句、手動選択、復元、カテゴリ別設定）、モデル自動切り替え（対象HTTPステータス、OFF設定、403の除外、有料・料金未確認・2.5系モデルの除外、404候補のスキップ、複数候補の優先順位）を確認します。

## Groq／Workers AIの代替モデル切り替え

GroqおよびCloudflare Workers AIでは、選択モデルが一時的なAPI障害・通信タイムアウト・モデル未提供（HTTP 404）などで利用できない場合、最後に取得・保存した同一プロバイダーのモデル一覧から最大3モデルを順に試します。認証エラー（401）、権限エラー（403）、入力不正（400）など、モデル変更で解決しないエラーでは切り替えません。代替モデル一覧が保存されていない場合は自動切り替えを行わないため、設定画面でモデル一覧を更新してください。代替モデルへの切り替えは現在の処理だけに適用し、ユーザーが選択した既定モデルは変更しません。代替モデルの料金・利用枠は選択モデルと異なる場合があるため、利用前に各プロバイダーの料金条件を確認してください。ログには実際に使用したモデルIDを記録します。
