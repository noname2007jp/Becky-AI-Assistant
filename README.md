# Becky AI Assistant

Becky! Internet Mail向けのGemini API連携AIアシスタントプラグインです。

## 現在の機能（0.47.0）

- 対象: Win32 (x86)、Visual Studio 2022、C++17、MBCS
- メール一覧・本文表示の右クリックメニューから起動
- 対象メールは1通。複数選択時は警告して処理を中止
- MIMEテキストを抽出して要約、複数回のAI相談、返信文案の作成が可能
- HTMLメールは段落・改行・箇条書きの構造を保持し、HTML文字参照をデコード
- 相談履歴を踏まえた返信文案の作成と、Becky!の通常返信・全員返信画面への挿入に対応
- 返信・全員返信の作成画面にある「Becky AI Assistant...」メニューからも返信文案を作成し、現在開いている返信画面へ直接挿入
- 新規メールの目的・補足条件から件名と本文を作成し、編集後にBecky!の作成画面へ反映
- 新規メール・返信・全員への返信の作成画面の右クリックメニューから、入力済み本文をGeminiで校正。修正前後を並べて確認し、校正結果を編集して明示確認後に適用
- 校正では必要最小限の修正を優先し、原文の社名・宛名・署名・引用・段落・改行を省略・変更しないよう指示。マスキング対象が校正結果から欠落した場合は、本文欠落を防ぐため結果の適用を拒否。校正結果を別モデルで再校正する場合は、直前の校正結果を次の入力として使用。元の本文は適用操作を行うまで保持
- 生成文案は編集可能。送信・送信操作は行わない
- 要約・返信・相談・新規メール作成・メール校正で共通のモデルカタログを使用
- 相談履歴は画面を閉じると消去し、ディスクには保存しない
- 添付ファイルはGemini APIへの送信対象外

## 個人情報のマスキング

Gemini APIへ送信するプロンプトを作成する直前に、ローカルでマスキングします。

- 自動検出の種類を設定画面で個別にON/OFF: メールアドレス、電話番号、郵便番号、IPv4アドレス、会社名、氏名、住所、口座・顧客・社員番号
- 追加登録語句も個別にON/OFF可能。会社名・氏名・部署名などを1行に1件ずつ登録
- 追加登録語句とマスキング種類の設定はWindows DPAPIで暗号化して保存
- 個人情報マスキングはメイン画面のGeminiモデル選択欄の横にある「マスキング」でON/OFF（初期値OFF、選択状態は保存）
- 設定画面ではマスキング対象の種類と追加登録語句を管理
- マスキングを有効にすると、要約・返信・相談・新規メール作成・メール校正の実行前に送信対象情報をプレビュー表示
- プレビュー上でマウス選択した語句を手動マスキングでき、同じ語句が送信内容内に複数ある場合はすべてマスク
- 初期選択モデルはGemini 3.5 Flash-Lite（解除したい場合はプレビューをキャンセルして再表示）
- プレビューで「この内容で送信」を選んだ場合だけGemini APIへ送信
- Geminiから返った文案は、表示前にローカルで元の語句へ戻す
- マスキング設定を復号できない場合は、外部送信を中止

自動検出は完全ではありません。氏名・会社名・住所など、確実に伏せたい語句は設定画面に登録してください。マスキング後の情報でも文脈から個人や組織が推測される可能性があります。送信前プレビューを必ず確認してください。

## Gemini APIモデル一覧の更新

設定画面の「APIモデルを更新」から、保存済みAPIキーでGemini APIの `models.list` を呼び出します。

- `generateContent` 対応のGemini/Gemmaテキスト生成モデルを抽出
- 音声・画像生成・埋め込み・Live・動画などの専用モデルは除外
- 「有料モデルも含める」をOFFにすると、Google公式料金ページのStandard表にあるInput priceのFree Tier列で無料と確認できたモデルだけを表示
- ONにすると、APIキーのモデル一覧に返された他のテキスト生成モデルも含める。料金区分が未分類のモデルはラベルで明示
- 料金ページはMarkdown形式を優先して取得し、StandardのInput price行を解析
- 更新結果は `%APPDATA%\\Becky-AI-Assistant\\models-catalog.txt` に保存
- 要約・返信・相談・新規メール作成・メール校正は、同じ保存済みモデル一覧を使用

無料枠の判定はモデル一覧の更新時にGoogle公式料金ページから取得したStandardのInput price / Free Tier欄に基づきます。Google側のページ構成が変更され解析できない場合は更新を中止し、既存カタログを保持します。また、料金ページで無料枠ありと判定されても、APIキーの権限・割り当て・地域・提供状況によって実際の生成リクエストが拒否される場合があります。

## 応答待ち・エラー処理

- Gemini APIの接続・送信・応答待ちにタイムアウトを設定（応答待ち30秒）
- 400 / 401 / 403 / 404 / 408 / 413 / 429 / 5xxを原因別に案内
- 404 / 408 / 429 / 5xx / 通信タイムアウト時は、設定ONなら無料枠ありと公式料金ページで確認済みの新しいFlashモデルへ最大2候補まで自動切り替え。2.5系はプロジェクトごとの利用制限があるため自動切り替え先から除外（403 / 認証・設定エラーは対象外）
- 有料・料金未確認モデルへの自動切り替えは行わず、切り替え後は画面に使用モデルを通知。無料枠の上限やGoogle側の課金設定により料金が発生する可能性があり、無課金を保証するものではありません
- 自動切り替えは設定画面でON/OFF可能（初期値ON）。代替モデルが見つからない場合は、先に設定画面からAPIモデル一覧を更新してください
- モデル更新と接続テストはバックグラウンドで実行
- 要約・返信・相談・新規メール作成・メール校正の生成処理はキャンセルを要求可能。処理終了後に画面を閉じる

## 手動マスキング

送信内容の確認画面で選択範囲を手動マスキングした場合、選択済みプレビューを元の送信プロンプトへ確実に適用します。返信文案ではプレビューとAPI送信で同一のプロンプト生成処理を使用し、全選択時にも選択内容全体が単一の `[MANUAL_n]` トークンとして送信されます。

## デバッグログ

設定画面の「詳細デバッグログ」を明示的にONにすると、Gemini API送信内容と応答の診断情報を記録します。

- 保存先: `%APPDATA%\\Becky-AI-Assistant\\debug.log`
- 記録項目: 操作種別、モデルID、マスキング状態、置換語句数、送信データサイズ、HTTPステータス、エラー
- マスキングがONの場合のみ、APIへ送信する直前のJSONペイロードを記録
- マスキングがOFFの場合は本文・プロンプトを記録せず、メタデータのみ記録
- ログは最大約2MBでローテーションし、旧ログを `debug.log.1` に保存
- ログにはマスキング後の送信文章が残ります。マスキングは匿名化を保証せず、未検出情報が残る可能性があるため、ログの取り扱いに注意し、検証後は削除してください
- APIキー、認証ヘッダー、Geminiからの回答本文は記録しません

デバッグログは初期状態でOFFです。

## APIキー・マスキング設定の保存

Gemini APIキー、追加マスキング語句、マスキング対象設定、安定性設定（デバッグログの有効・無効を含む）は、Windows DPAPI（現在のWindowsユーザーに紐づく暗号化）で保存します。

- APIキー: `%APPDATA%\\Becky-AI-Assistant\\gemini-key.dat`
- マスキング語句: `%APPDATA%\\Becky-AI-Assistant\\pii-mask.dat`
- マスキング対象: `%APPDATA%\\Becky-AI-Assistant\\pii-options.dat`
- 安定性設定: `%APPDATA%\\Becky-AI-Assistant\\reliability-options.dat`

別のWindowsユーザーでは復号できません。平文のAPIキー・追加マスキング語句・マスキング設定は保存しません。

## テスト

Gemini APIのJSON応答解析は全機能で共通化し、Unicodeエスケープ（サロゲートペアを含む）、改行・引用符などのJSONエスケープ、不正な文字列値を回帰テストします。

Win32 Releaseビルド時に回帰テストを実行します。非同期処理では、ワーカースレッドの起動順序・完了通知・キャンセル時の結果破棄を専用テストで確認します。また、Gemini API応答が2MBを超えた場合は不完全な応答を成功扱いせず、明示的なエラーとして扱います。MIME本文抽出（UTF-8 / Shift_JIS / EUC-JP / ISO-2022-JP、Base64、Quoted-Printable、入れ子multipart、HTML文字参照・段落改行、添付ファイル除外、長文・サイズ上限、空メール）、個人情報マスキング（ON/OFF、各種検出、追加登録語句、手動選択、復元、カテゴリ別設定）、モデル自動切り替え（対象HTTPステータス、OFF設定、403の除外、有料・料金未確認・2.5系モデルの除外、404候補のスキップ、複数候補の優先順位）を確認します。

## ビルド

Visual Studio 2022 の「x86 Native Tools Command Prompt」から実行します。

```bat
cmake -S . -B build -G "Visual Studio 17 2022" -A Win32
cmake --build build --config Release
```

生成物: `build\\Release\\Becky-AI-Assistant-47.dll`
